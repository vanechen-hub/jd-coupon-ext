# jd-coupon-ext（京东定时领券扩展）

Chrome MV3 扩展：定时识别京东「超补好运券」等半点 / 整点券按钮并自动点击领取。
与 universal-clicker 配合（双扩展分别盯京东与芒果），避免手动错过放券时间。

## 功能
- 10:30 / 16:30 半点券识别（`HALF_TARGET` 面额优先 5-4，退而「超补好运券」系列）
- `NOTCOUPON` 黑名单过滤「搜索 / 购物车」等误判按钮
- 可见态判定，隐藏孪生图不误触发
- 每日 10:20 / 16:20 自动 reload 兜底

## 使用
1. `chrome://extensions` → 开发者模式 → 加载已解压的扩展
2. 扩展自动在设定时间巡检京东券页
